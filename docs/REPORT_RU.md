# FireLens — отчёт о доработке

Дата: 14 ноября 2026 года. Исходник: архив `firelens.zip` из вложений указанного чата. Скачанная папка пользователя не изменялась.

## Найдено и исправлено

- Архив содержал рабочий `src` и несовместимую незадействованную копию `app/applet/src`. Во второй были вымышленные метрики, заявления об авиационной валидации, статические графики и искусственный очаг при поиске координат. В итоговом проекте оставлен один исходный каталог; эти утверждения и генерация очага исключены.
- Сохранены композиция, цвета, карта, правая панель, временная шкала и четыре вкладки. Объединены EN/RU, светлая и тёмная темы, оформление справки/фильтров/графиков, сохранение предпочтений.
- Четыре разные сетевые подложки: standard/dark OpenFreeMap, Esri World Imagery, OpenTopoMap. Исправлена загрузка отдельного worker MapLibre: в первой браузерной проверке из-за него карта была пустой. После исправления карта отображала настоящие границы, точки и кластеры.
- Компактная прокручиваемая панель слоёв, фильтры сенсоров, дат/UTC, FRP. Страны приближаются по геометрии; неофициальные области не получают вымышленных прямоугольных границ. Загруженные Polygon/MultiPolygon отображаются как пользовательские контуры. Поиск городов использует Open-Meteo/GeoNames, координат — локальную проверку диапазонов. Поиск не создаёт наблюдения.
- Реализованы серверный FIRMS Area API, ключ только на сервере, тайм-аут, короткий кеш, ограничение частоты и проверка параметров. При отсутствии ключа, сетевой ошибке или неполной загрузке данные не подменяются DEMO.
- Импорт нескольких FIRMS CSV, native confidence MODIS/VIIRS, UTC, координаты, FRP, явное число отклонённых записей, пространственный отбор и удаление точных дублей. Агрегаты реального импорта помечены partial; пропуски не превращаются в нули.
- Шаблон JSON теперь синтетический, без фиктивных результатов гармонизации. Флаг `verified:true` из внешнего JSON не принимается за доказательство научной валидации.

## Что именно рассчитывается

Эксперимент сравнивает суммы FRP MODIS и VIIRS в общей сетке 0,25° за сутки UTC. Включаются только ячейки/даты с детекциями обоих сенсоров. На первых 70% уникальных дат оценивается неотрицательный коэффициент OLS через начало координат MODIS → VIIRS; на последующих датах вычисляются MAE, RMSE, bias и исходный RMSE. Минимум: 6 разных дат, 5 обучающих и 3 отложенных пары. При недостатке данных коэффициент и ошибки отсутствуют. Экспорт JSON сохраняет метод, единицы, размеры выборок и границу разделения дат.

Это исследовательская калибровка FRP, **не научно валидированная гармонизация исторической пожарной активности**. Она не меняет исторические ряды в остальных вкладках и не создаёт искусственные доверительные интервалы.

## Проверки

- Проверка TypeScript (`npm run lint`), модульные тесты (`npm test`) и production-сборка (`npm run build`). Окончательные результаты перечислены в `FireLens/docs/verification.txt`.
- Тесты покрывают исходные фильтры/периоды/границы, маркировку DEMO, CSV/UTC/confidence, дубли, недостаточное перекрытие, известный коэффициент на синтетических данных и независимость отложенных дат, отказ доверять `verified:true`.
- Проверен публичный NASA CSV MODIS за 24 часа: 9 893 корректные записи, 0 отклонённых. В bbox выбранного региона попали 3. Публичный VIIRS CSV в момент загрузки содержал только заголовок: 0 записей. Коэффициент на этих реальных данных не рассчитан — 0 пар. Пример импорта и хеши включены в `examples`.
- Браузер: переключение тем/EN-RU, четырёх подложек, вкладок; поиск Astana вернул реальные результаты GeoNames; при отсутствии FIRMS_MAP_KEY получено явное сообщение 503. Наличие действующего ключа и успешный ответ защищённого Area API не проверены.
- Сборка предупреждает о размере основного JS (~4,15 MB до gzip, ~1,29 MB gzip). Это ограничение производительности, не ошибка сборки. Возможны предупреждения отсутствующих декоративных иконок внешнего стиля.

## Существенные ограничения

1. Нет научной/полевой валидации, облачных масок, контроля полноты пролётов, поправок на угол наблюдения, сезонность, тип поверхности, насыщение и различия разрешения. FRP суммируется по детекциям/пролётам; сетка в градусах не равновеликая. VIIRS — сравнительный сенсор, не наземная истина. Отбор только совместно обнаруженных ячеек даёт смещение выборки.
2. Нет исторической реконструкции 2000–2026, площади выгорания, причин пожаров, оперативного прогноза опасности или PM2.5. Исходный демонстрационный исторический календарь остаётся синтетическим. Недели — существующая схема W1–W52 с объединением хвоста года, не ISO-8601.
3. Импортированный пользовательский CSV/JSON сам по себе не доказывает происхождение данных. Метка реальных/импортированных данных означает режим источника, а не его независимую сертификацию. NRT — предварительные продукты.
4. Настоящие подложки и глобальный поиск зависят от внешних сервисов. Fallback Natural Earth — упрощённая карта; он не эквивалентен спутниковой/топографической подложке. Названия географических объектов и некоторые исходные описания сохраняют язык поставщика. Полностью автономной работы всех подложек нет.
5. Natural Earth — обобщённая картография; специальные случаи пересечения 180-го меридиана и полярных областей требуют отдельной доработки. Пользовательские полигоны проверяются по типу и координатам, без исправления самопересечений. Полноценная топологическая валидация и произвольные CRS не реализованы.
6. Сервер рассчитан на локальный запуск. Перед публичным размещением нужны управление квотами/доступом и условия использования картографических поставщиков. Ключ NASA в поставку не входит. Статический preview не обслуживает API.
